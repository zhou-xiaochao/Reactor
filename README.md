# reactor server（with protocol：HTTP）

### 可支持多种协议的高并发服务器

基于 C++ Reactor 模型实现的**高性能、可扩展、模块化**并发服务器，支持多种应用层协议，可轻松扩展自定义协议。

------

## ✨ 核心特性

- **多协议支持**：内置 HTTP 协议，可快速扩展自定义协议
- **配置驱动**：通过 `config.json` 灵活配置服务器行为
- **自动配置生成**：无配置文件时自动创建默认配置
- **解决 TCP 粘包**：通过协议分隔符机制处理粘包问题
- **多种 IO 多路复用**：支持 epoll /poll/select 切换
- **模块化架构**：核心、网络、协议、线程完全解耦

------

## 📝 配置文件说明

服务器启动时会自动读取工作目录下的 `config.json`。

**若文件不存在，程序会自动创建并写入默认配置**。

### 默认配置（default_cfg）

| json                                                         |
| ------------------------------------------------------------ |
| **{<br/>    "buffer_end_sign": "\r\n",<br/>    "dispatcher_way": "epoll",<br/>    "protocol_type": "http"<br/>}** |

| 字段              | 说明                                               |
| ----------------- | -------------------------------------------------- |
| `buffer_end_sign` | 协议数据结束分隔符，用于解决 **TCP 粘包问题**      |
| `dispatcher_way`  | Reactor 模型使用的 **IO 多路复用方式**，默认 epoll |
| `protocol_type`   | 启用的应用层协议类型，默认 http                    |

## 🚀 适用场景

- 高并发 TCP 服务器
- HTTP 协议解析与响应
- 自定义私有协议服务器
- 学习 Reactor 模型与高性能服务端开发
